# Observal

[Observal](https://observal.io) is a self-hosted registry for your coding agent extensions. Set up Observal, define the scope, and share your Skills, MCPs, and Agents with your peers.

Developer-first, open-source with a built-in insight engine. Stop hosting your skills, MCPs, and other coding agent extensions on git. Use Observal and see the difference.
